Find the core. Follow the meaning.

REden helps you focus on the words that carry a sentence’s meaning. By bringing its essential structure into view or gently softening less important words, it is designed to support faster reading and clearer understanding—while keeping the full text in place.

Available in the preview

Emphasis shaped by words and meaning.

REden combines sentence structure with word frequency and word parts to choose which letters to bold. Important words receive stronger emphasis, while the full text stays visible.

Future direction

More languages. More ways to understand.

Our long-term goal is to bring REden to more languages.

Languages build sentences differently, so subject–verb–object will not apply the same way everywhere.

Developer preview

Get the extension.

One file for Chrome, Microsoft Edge and Firefox.

Go to the repository

Chrome

  1. Unzip the extension file.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and pick the unzipped folder.

Microsoft Edge

  1. Unzip the extension file.
  2. Open edge://extensions and turn on Developer mode.
  3. Choose Load unpacked and pick the unzipped folder.

Firefox

  1. Unzip the extension file.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and pick manifest.json in the folder.

Needs the backend

Unzip the backend, run pip install -r requirements.txt, then python server.py.
